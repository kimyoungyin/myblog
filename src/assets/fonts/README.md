# Noto Sans KR

The OG image routes use the Korean subset of Noto Sans KR so Korean titles do
not depend on a runtime Google Fonts request.

- Source: [Google Fonts Noto Sans KR](https://github.com/google/fonts/tree/main/ofl/notosanskr)
- License: [SIL Open Font License 1.1](https://scripts.sil.org/OFL)
- Download source: `fonts.gstatic.com` URLs generated from the Google Fonts CSS
  API with the Korean subset selected.

`NotoSansKR-Regular.ttf` and `NotoSansKR-Bold.ttf` are used by
`next/og`/Satori and are intentionally kept as TTF files.
